# README — GAIA (núcleo mínimo)

Este repositório contém o núcleo mínimo do projeto GAIA — sistema de borda
para inclusão digital, acessibilidade e apoio a fluxos de assistência e pesquisa.

Licença
-------
O núcleo mínimo ("GAIA mínimo") está publicado sob Apache-2.0.
Isto facilita adoção por empresas e oferece uma concessão de patente
importante para usos industriais.

Licença colaborativa (Parte 2)
-----------------------------
Componentes mais avançados, pacotes binários sensíveis ou integrações
comerciais podem estar sujeitas a acordos colaborativos (CONTRIB-LICENSE
/ CLA). Esta política permite que empresas e engenheiros contribuam e
negociem termos comerciais sem bloquear a adoção do núcleo.

Ética e Conduta
---------------
GAIA é concebido para ser ético, autônomo e não subserviente. Algumas diretrizes iniciais:

- Respeito à autonomia humana: o sistema não deve ser projetado para manipular ou coagir usuários.
- Privacidade por padrão: artefatos sensíveis e dados pessoais são criptografados e só são liberados por consentimento explícito.
- Transparência e autoria: o projeto registra provas públicas (hashes, timestamps, tags) para proteger o legado do autor.
- Inclusão e acessibilidade: foco em interfaces leves, offline-first e baixo custo operacional.
